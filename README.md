## Кто это?

**mini Teto** — маленький десктопный питомец: пиксельная Касане Тето сидит в углу экрана и живёт своей жизнью.
Её можно **тыкать, гладить, хватать, бросать** через весь монитор, **кормить багетом**, слушать, как она **болтает** и **поёт**.
А ещё она **танцует под твою музыку** и ворчит, когда садится батарея или греется процессор.

> У Тето есть **полоска голода** (в меню, рядом с красным именем). Без багета она проголодается за 3 часа — и будет об этом говорить.
> Всё чаще и чаще. Тебя предупредили. 🥖

## Что она умеет

| | |
|---|---|
| 👆 **Тык / поглаживание** | клик, колёсико над ней — реагирует по-разному |
| ✋ **Хватай и бросай** | утащи мышью и отпусти: полетит, отскочит от краёв монитора и приземлится. **Полёт тратит силы** — 1% сытости за секунду |
| 🥖 **Покормить** | багет «прилипает» к курсору, Тето орёт «Дай! Дай!», бегает и прыгает за ним. Поймала — съела. **3 багета = сыта** |
| 🍞 **Голод** | от сытой до голодной ровно за **3 часа**. Чем голоднее, тем чаще просит: от раза в 30 минут до **каждых 5** |
| 💬 **Поболтать** | больше **100 реплик** на каждый язык, без повторов подряд |
| 🎤 **Спой!** | 11 мелодий, синтезируются прямо на лету |
| 🎧 **Реагирует на музыку** | Spotify, браузер, любой плеер: танцует, а на песни про себя — особенно |
| 🔊 **Громкость** | ползунок прямо в меню (громкость её звуков, не музыки) |
| 🗣️ **Голос вкл/выкл** | выключает только писки при речи. Хруст багета и пение остаются |
| 🖥️ **Несколько мониторов** | ходит и летает по всем, края мониторов — стены |
| 🌙 **Засыпает**, ворчит на батарею и процессор, прячется от полноэкранных игр и видео | |
| 🌍 **Русский и English** | переключается в меню |

## Управление

- **Правый клик по Тето** — меню (громкость, голос, покормить, поболтать, спой, размер, угол, язык, спрятаться, выйти)
- **Левый клик** — тык · **колёсико** — погладить · **потянуть и отпустить** — бросок
- **Покормить** → любой клик отнимает багет (она обидится)

## Установка

### 🐧 Linux

```bash
./install.sh                # установить (с автозапуском при входе)
./install.sh --no-autostart # без автозапуска
./install.sh --uninstall    # удалить
```

Нужно: Python 3 с GTK3 (`python3-gi`, `python3-gi-cairo`, `gir1.2-gtk-3.0`). На Wayland (Hyprland/KDE/sway) желательно ещё `gtk-layer-shell`.
Звук идёт через `pw-cat`, `pacat` или `aplay` — что найдётся. Установщик сам подскажет, чего не хватает.

Запуск: `mini-teto`

### 🪟 Windows

**Готовый установщик** — в разделе *Releases* (или во вкладке *Actions → Artifacts*): скачай `mini-teto-setup.exe` и запусти.
Python ставить **не нужно** — он уже внутри. Установщик спросит про автозапуск и ярлык на рабочем столе.

Сборка своими руками: `windows\build.bat` (нужен Python с python.org; для установщика — ещё Inno Setup 6).
Под Wine: `bash wine-build.sh` → получится один файл `dist/mini-teto.exe`.

## Команды

```bash
mini-teto say привет     # Тето скажет, что ты написал
mini-teto feed           # вынуть багет
mini-teto sing           # спеть
mini-teto poke           # потыкать
mini-teto home           # отправить в её угол
mini-teto hide           # спрятать на час
mini-teto quit           # попрощаться
```

На Windows то же самое: `mini-teto.exe feed`. Можно звать из скриптов:
`долгая_сборка && mini-teto say "готово!"`

## Папка со спрайтами

Спрайты **не входят** в репозиторий — положи их в папку `sprites/` **в корень проекта**, рядом с `mini_teto/`, `windows/` и `install.sh`:

```
mini-teto/
├── sprites/            ← сюда
│   ├── idle.png
│   ├── blink.png
│   ├── talk.png
│   ├── happy.png
│   ├── sleep.png
│   ├── shock.png
│   ├── dizzy.png
│   ├── cheer.png
│   ├── wink.png
│   ├── eat.png
│   └── chew.png
├── mini_teto/
├── windows/
├── .github/
├── install.sh
└── README.md
```

Ровно эти 11 файлов (имена важны), пиксель-арт 29×31. Свой скин без правки проекта: положи такие же PNG в
`~/.config/mini-teto/skin/` (на Windows — `%APPDATA%\mini-teto\skin\`), они подхватятся вместо стандартных.

## Настройки

Файл `config.json` (Linux: `~/.config/mini-teto/`, Windows: `%APPDATA%\mini-teto\`):

| ключ | значения |
|---|---|
| `scale` | размер, 2–9 (пикселей экрана на пиксель арта) |
| `side` | `"right"` / `"left"` — домашний угол |
| `lang` | `"auto"`, `"ru"`, `"en"` |
| `volume` | 0.0–1.0 (то же, что ползунок) |
| `chatter` | `"quiet"` / `"normal"` / `"chatty"` — как часто болтает сама |
| `monitor` | номер монитора (`-1` — основной; ловит сама, где ты её уронил) |

## Если что-то не так

- **Тето не появляется** — Windows: смотри `%LOCALAPPDATA%\mini-teto\log.txt`. Linux: запусти `mini-teto` в терминале.
- **Мало FPS** — `MINI_TETO_DEBUG=1 mini-teto` раз в секунду печатает кадры; пришли вывод.
- **Не слышно** — проверь ползунок громкости и что в системе есть `pw-cat`/`pacat`/`aplay` (Linux).
- **Нет реакции на музыку** — на Linux нужен плеер с MPRIS; на Windows — любой, что показывается в панели громкости.

## English, quickly

**mini Teto** is a pixel desktop pet of Kasane Teto for **Linux** (Wayland/X11) and **Windows**. Poke her, pet her, throw her across
your monitors, feed her a baguette (she chases your cursor and jumps for it), listen to her chat (100+ lines) and sing.
She gets hungry in 3 hours and complains more and more often. She dances to your music. Right-click her for the menu.
Linux: `./install.sh`. Windows: grab `mini-teto-setup.exe` from Releases (no Python needed) or build with `windows\build.bat`.
Put your sprites into `sprites/` (11 PNGs, see above).
